loop crystalCount read tide:int litBy:int myStreak:int
write WAIT

STATEMENT
Light crystals with your lamp's beam: place mirrors to bend it.

INPUT
reef: size*size characters, row by row from y = 0: cell (x, y) is reef[y*size+x]; . empty, # rock, 1-3 crystal value, A-D lamp of player 0-3 (A = you; the number of lamps is the number of players)
size: width and height of the reef
myScore: your score
mirrors0: mirrors you can still place; mirrors1-mirrors3: the other players' (-1 if eliminated or missing)
mirrorCount: number of mirrors on the reef
mirrorType: 0 for /, 1 for \, -1 for another player's pending mirror
lock: turns before it can be turned (0 = can be turned, -1 = pending: does not bend beams yet)
life: active turns left before it shatters (-1: never wears; 0: shattered at the end of last turn, cell now empty)
crystalCount: number of crystals; one line each, in reef order (by y, then x)
tide: awake for tide more turns if > 0, asleep for -tide more turns if < 0, 0 = always awake
litBy: player who lit it alone last turn, -1 nobody, -2 several
myStreak: your streak on this crystal, 0 to 4

OUTPUT
PLACE x y type | TURN x y | WAIT, optionally followed by a message
